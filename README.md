# Crypto Market Circle

This repository contains a collection of HTML pages serving dual purposes: a crypto trading platform interface and exam preparation materials.

## Contents

*   **Crypto Market Circle Interface**
    *   `login.html`: A login page for the "Crypto Market Circle" secure trading platform.

*   **Exam Preparation (SAA-C03)**
    *   `index.html`: The main landing page linking to various test modules and the email page.
    *   `Test1.html`, `Test2.html`, `Test3.html`: Practice test pages (likely for AWS Certified Solutions Architect - Associate SAA-C03).
    *   `Email.html`: An associated email page.

## Usage

These are static HTML files. You can view them by opening the files directly in a web browser.
